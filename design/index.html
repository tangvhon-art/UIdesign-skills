设计令牌（Tokens）

以 CSS 变量形式提供，便于全局换肤/二次开发。

./styles/tokens.css
--sw-primary --sw-success --sw-warning --sw-error 
/* 关键 Token（摘录） */
:root{
  --sw-primary: #1677ff;
  --sw-bg-layout: #f0f2f5;
  --sw-radius: 6px;
  --sw-shadow-2: 0 6px 16px rgba(0,0,0,.08);
}
